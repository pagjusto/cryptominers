## Como interpretar esta documentação

- **Regra definida:** decisão já estabelecida para o jogo.
- **A definir:** assunto que ainda precisa de decisão antes de ser tratado como regra oficial.
- **Etapa futura:** funcionalidade documentada para planejamento, mas que não deve ser implementada nesta fase.

Os textos públicos devem explicar o funcionamento sem expor detalhes internos de segurança, implementação ou operação do servidor.

## Estado do projeto

As regras descritas aqui representam as decisões de produto já registradas. Isso não significa que todas estejam implementadas ou disponíveis na versão atual do jogo. A implementação deve ser acompanhada separadamente no código e nos testes.

Pagamentos, checkout, depósitos, saques e cobranças recorrentes estão reservados para uma etapa conjunta futura. Nenhum fluxo de cobrança deve ser adicionado como parte desta documentação.
